Nature Chemistry 2024 arxiv ↗

Augmenting large language models with chemistry tools

GPT-4 equipped with 18 specialized chemistry tools substantially outperformed bare GPT-4 on chemistry tasks, and successfully planned multi-step synthesis of novel compounds autonomously.

What this paper does
Ask GPT-4 chemistry questions without any scaffolding, and it often delivers wrong information with confidence. Chemistry demands precision, so this is a real problem. ChemCrow's solution: give GPT-4 18 specialized chemistry tools and let it call them as needed. Tools for molecular structure calculation, literature search, safety data lookup, synthesis pathway planning. Instead of generating answers from scratch, the model retrieves accurate information through tools and constructs its response from there. It successfully planned and autonomously executed multi-step synthesis of novel compounds.
Takeaway
◆ Tool use doesn't just improve accuracy — it changes the failure mode. GPT-4 without tools fails confidently (hallucination). ChemCrow fails more gracefully because it can cross-check its reasoning against real databases. "What tools to give the model" matters as much as "which model to use" — a framing that shapes how I think about AI system design for materials science.
◇ The choice of 18 tools encodes assumptions about the chemistry research workflow. An agent for battery electrolyte discovery would need a fundamentally different toolset. Defining that tool set — what chemical property calculators, what synthesis feasibility checks — was one of the core design decisions in my Deepspace project.
